# MILNI

**People. Traditions. Together.**

MILNI is a web-first private social platform for Indian weddings. Couples and organisers create a wedding space and guests join through a private invitation link, QR code or invitation code.

## Product principles

- Wedding-scoped private social network
- Flexible across Indian cultures, religions, mixed weddings and custom traditions
- Organisers choose useful tradition templates, then own and customise their schedule and explanations
- Web/PWA first, responsive and useful during low-connectivity wedding weekends
- Privacy and explicit wedding membership are foundational

## MVP journey

Create Wedding → Choose Traditions → Build Schedule → Invite Guests → Guest Joins → Wedding Home

## Planned stack

- Next.js + React + TypeScript
- SCSS Modules + CSS custom properties
- PostgreSQL / Supabase
- Drizzle ORM
- Zod
- React Hook Form
- PWA/service worker

## Initial product areas

Guest: Home, Schedule, Events, Travel, Menu, Music, Photos, Guests, Singles, Live, Profile.

Organiser: Overview, Schedule, Guests, Venues, Transport, Menu, Music, Announcements, Photos, Settings.

## Status

Foundation phase. The supplied MILNI mockups are the visual and UX source of truth.
